# 인천 산업정책 조사

인천 6대 전략산업의 기업 수요와 정책·사업을 같은 구조로 정리하는 정책핏 인천의 조사 자료 저장소다. 정책 간 연결과 공백을 검토하고, 공개자료로 검증할 수 있는 MVP를 선정하는 데 사용했다.

## 유소민의 역할

성과데이터·검증설계(C) 자료를 정리·검토했다. 정책·예산 대응표와 정답셋을 구성하고 데이터로 검증할 수 있는 MVP를 비교했다.

[주요 작업과 관련 자료](docs/CONTRIBUTIONS.md)

## 분석 범위

청년정책 자료는 조사 방법 검증에 사용하고, 6대 산업 자료는 현재 산업 분석에 사용했다. 각 자료의 `scope`와 출처 등급을 함께 확인한다. 원문 연결·교차검증이 남은 항목은 잠정 결과다.

후속 앱·제품 설계는 [정책핏 인천](https://github.com/rokmc1893/INU-X-UOU)에서 관리한다.
