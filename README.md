# 인천 산업정책 조사 워크스페이스

> **에이전트에게: 여기가 진입점이다.**
> 어떤 작업을 요청받았든, 먼저 §2에서 담당 조사자 폴더를 찾고 그 폴더의 `README.md`를 읽어라.
> 그 README에 적힌 금지사항을 지키지 않으면 해당 조사자의 산출물이 무효가 된다.

---

## 1. 이 저장소의 목적

인천 산업정책의 **수요**와 **공급(정책·사업)**을 같은 구조로 지도화해서, 신규 정책이 정말 필요한지 아니면 기존사업을 보완·연결하면 되는지를 판단할 기초자료를 만든다.

조사자별로 담당 영역이 나뉘어 있고, 각자 독립된 폴더에서 작업한 뒤 공통 규칙으로 서로의 결과를 연결한다.

---

## 2. 폴더 구조

```
incheon-research/
├── README.md                    ← 지금 이 파일
├── shared/
│   └── CONVENTIONS.md           ← 전 조사자 공통 규칙. 반드시 읽는다
└── researchers/
    └── B_industry_portfolio/    ← 조사자 B (산업수요·사업 포트폴리오)
        ├── README.md            ← B 작업의 진입점
        ├── SCHEMA.md            ← B 데이터 정의서
        ├── CHANGELOG.md
        ├── analysis/            ← 분석 본문
        ├── data/                ← CSV 산출물
        └── scripts/             ← 재생성 스크립트
```

**조사자 폴더를 추가할 때**는 `researchers/<코드>_<영역>/` 형식을 쓰고, 최소 `README.md`와 `CHANGELOG.md`를 둔다.

## 4. 조사자 B 요약 (상세는 해당 폴더 README)

**답한 질문** 인천 6대 전략산업(바이오·반도체·로봇·디지털데이터·미래차·항공)의 실제 수요와 현재 정책을 같은 축에 놓았을 때 무엇이 비어 있는가.

**핵심 발견 셋**

1. **행정구역이 2026-07-01에 바뀌었다** — 2군 8구 → 2군 9구. 군·구 단위 데이터를 다루는 모든 조사자에게 영향. 개편 전후 자치단체코드 매핑표(R-02) 확보가 최우선
2. **금융·투자 대응 사업이 6개 산업 전부에 없다** — 다만 타 부서 소관 가능성을 배제해야 결론이 됨
3. **미래차만 수요신호 0건** — 조사 실패인지 정책 부재인지 미판별

**한계** 52건 중 34건이 언론보도 수준. 원문 연결 0건, 중복 확정 0건. 모든 판단이 잠정이다.

## 5. 전 조사자 공통 원칙

`shared/CONVENTIONS.md`에 상세히 있으나, 셋만 여기 옮긴다.

1. **빈칸은 실패가 아니라 조사 결과다.** `UNKNOWN`을 추정치로 채우지 않는다
2. **출처 없는 행은 등재하지 않는다.** 모든 주장에 `source_url`이 붙는다
3. **"후보"와 "확정"을 구분한다.** 반대가설을 배제하지 않은 판정은 확정이 아니다

---

## 6. 기여 방법

```bash
git clone <이 저장소>
cd incheon-research
# 담당 조사자 폴더의 README.md와 SCHEMA.md를 먼저 읽는다
# scripts/의 파이썬을 수정하고 재실행한다 (CSV 직접 편집 금지)
# CHANGELOG.md에 변경을 기록한다
```

커밋 메시지는 `[조사자코드] 유형: 내용` 형식을 권장한다. 예: `[B] ADD: 항공 MRO 사업 3건 등재`
